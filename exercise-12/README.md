Save and restore uncommitted changes using git stash.

## Objective
Stash working tree changes, inspect stash list, apply stashed modifications, commit them, and drop the stash.

## Commands Used
- git stash push
- git stash list
- git stash apply
- git stash drop
- git commit

## Expected Result
Changes are stashed, restored, committed, and the stash queue is cleanly emptied.
